# ATLAS Deployment Guide

Complete step-by-step instructions for deploying the ATLAS backend to production on various platforms.

## Quick Comparison

| Platform | Cost | Setup Time | Difficulty | Best For |
|----------|------|-----------|------------|----------|
| **Railway** | Free tier + $5/mo | 5 min | ⭐ Very Easy | Beginners - Recommended |
| **Render** | Free tier + $7/mo | 5 min | ⭐ Very Easy | Good free tier |
| **Heroku** | $7-50/mo | 10 min | ⭐⭐ Easy | Classic choice |
| **Vercel** | Free tier + pay-as-you-go | 5 min | ⭐⭐ Easy | Serverless, fast |
| **AWS Lambda** | Pay-as-you-go | 20 min | ⭐⭐⭐ Moderate | Heavy usage, complex |
| **Google Cloud Run** | Free tier + pay-as-you-go | 15 min | ⭐⭐⭐ Moderate | GCP ecosystem |
| **DigitalOcean** | $4/mo | 15 min | ⭐⭐⭐ Moderate | Full control |

## ⭐ Recommended: Railway (Easiest)

### Step 1: Prepare Your GitHub Repository

Your repository already has all the code committed. Make sure:
- ✅ `server.js` is in `atlas-backend/` folder
- - ✅ `package.json` is in `atlas-backend/` folder
  - - ✅ `.env.example` is documented
    - - ✅ `README.md` has instructions
     
      - ### Step 2: Deploy on Railway
     
      - 1. **Go to Railway.app**
        2.    - Visit https://railway.app
              -    - Click "Create a new project" or "Deploy from GitHub"
                   -    - Sign in with GitHub
                    
                        - 2. **Connect Your Repository**
                          3.    - Select your GitHub repository: `myportfolio-KathleenCasto`
                                -    - Railway will automatically detect Node.js project
                                 
                                     - 3. **Set Root Directory** (Important!)
                                       4.    - In Railway dashboard, go to Settings
                                             -    - Set "Root Directory" to `atlas-backend`
                                                  -    - This tells Railway where the server.js file is
                                                   
                                                       - 4. **Add Environment Variables**
                                                         5.    - Click "Variables" tab
                                                               -    - Add each variable from `.env.example`:
                                                                    -      ```
                                                                    -       ANTHROPIC_API_KEY = sk-ant-... (from https://console.anthropic.com)
                                                                    -        SUPABASE_URL = https://your-project.supabase.co
                                                                    -         SUPABASE_KEY = your-anon-key
                                                                    -          PORT = 3001
                                                                    -           NODE_ENV = production
                                                                    -            ```
                                                                
                                                                    -        5. **Deploy**
                                                                    -       - Railway automatically deploys on every GitHub push
                                                                    -      - You'll get a public URL like: `https://atlas-backend-production.up.railway.app`
                                                                    -     - Click the URL to test your deployment
                                                                
                                                                    - 6. **Test the API**
                                                                      7.    ```bash
                                                                               curl https://atlas-backend-production.up.railway.app/api/health
                                                                               ```

                                                                            7. **Update Frontend**
                                                                            8.    - In your portfolio frontend, update the API URL:
                                                                                  -    ```javascript
                                                                                          const ATLAS_API_URL = 'https://atlas-backend-production.up.railway.app';
                                                                                          ```

                                                                                                                                                                                      ### Step 2: Login and Create App
                                                                                                                                                                                      
                                                                                                                                                                                      ```bash
                                                                                                                                                                                      # Login to Heroku
                                                                                                                                                                                      heroku login

                                                                                                                                                                                      # Create new app
                                                                                                                                                                                      heroku create atlas-backend-yourname

                                                                                                                                                                                      # Set root directory to atlas-backend
                                                                                                                                                                                      heroku config:set PROJECT_PATH=atlas-backend
                                                                                                                                                                                      ```
                                                                                                                                                                                      
                                                                                                                                                                                      ### Step 3: Add Procfile
                                                                                                                                                                                      
                                                                                                                                                                                      Create file: `Procfile` in project root (NOT in atlas-backend folder)
                                                                                                                                                                                      
                                                                                                                                                                                      ```
                                                                                                                                                                                      web: cd atlas-backend && npm start
                                                                                                                                                                                      ```
                                                                                                                                                                                      
                                                                                                                                                                                      ### Step 4: Set Environment Variables
                                                                                                                                                                                      
                                                                                                                                                                                      ```bash
                                                                                                                                                                                      heroku config:set ANTHROPIC_API_KEY=sk-ant-...
                                                                                                                                                                                      heroku config:set SUPABASE_URL=https://your-project.supabase.co
                                                                                                                                                                                      heroku config:set SUPABASE_KEY=your-anon-key
                                                                                                                                                                                      heroku config:set NODE_ENV=production
                                                                                                                                                                                      ```
                                                                                                                                                                                      
                                                                                                                                                                                      ### Step 5: Deploy
                                                                                                                                                                                      
                                                                                                                                                                                      ```bash
                                                                                                                                                                                      # Push to Heroku
                                                                                                                                                                                      git push heroku main

                                                                                                                                                                                      # View logs
                                                                                                                                                                                      heroku logs --tail
                                                                                                                                                                                      ```
                                                                                                                                                                                      
                                                                                                                                                                                      ### Step 6: Get Your URL
                                                                                                                                                                                      
                                                                                                                                                                                      ```bash
                                                                                                                                                                                      heroku apps:info atlas-backend-yourname

                                                                                                                                                                                                            "use": "@vercel/node"
                                                                                                                                                                                                          }
                                                                                                                                                                                                        ],
                                                                                                                                                                                                        "routes": [
                                                                                                                                                                                                          {
                                                                                                                                                                                                            "src": "/(.*)",
                                                                                                                                                                                                            "dest": "atlas-backend/server.js"
                                                                                                                                                                                                          }
                                                                                                                                                                                                        ]
                                                                                                                                                                                                      }
                                                                                                                                                                                                      ```

                                                                                                                                                                                                                              -    - Click "Import"
                                                                                                                                                                                                                               
                                                                                                                                                                                                                                   - 3. **Configure Project**
                                                                                                                                                                                                                                     4.    - **Framework**: "Other"
                                                                                                                                                                                                                                           -    - **Root Directory**: `.` (root)
                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                - 4. **Add Environment Variables**

                                                                                                                                                                                                                                                                                 gcloud projects create atlas-backend

                                                                                                                                                                                                                                                                                 gcloud config set project atlas-backend

                                                                                                                                                                                                                                                                                 ```dockerfile
                                                                                                                                                                                                                                                                                 FROM node:18-alpine

                                                                                                                                                                                                                                                                                 WORKDIR /app

                                                                                                                                                                                                                                                                                 COPY package*.json ./
                                                                                                                                                                                                                                                                                 RUN npm ci --only=production

                                                                                                                                                                                                                                                                                 COPY . .

                                                                                                                                                                                                                                                                                 EXPOSE 3001

                                                                                                                                                                                                                                                                                 CMD ["npm", "start"]
                                                                                                                                                                                                                                                                                 ```

                                                                                                                                                                                                                                                                                 gcloud run deploy atlas-backend \
                                                                                                                                                                                                                                                                                   --source . \
                                                                                                                                                                                                                                                                                   --platform managed \
                                                                                                                                                                                                                                                                                   --region us-central1 \
                                                                                                                                                                                                                                                                                   --set-env-vars=ANTHROPIC_API_KEY=sk-ant-...,SUPABASE_URL=...,SUPABASE_KEY=...,NODE_ENV=production \
                                                                                                                                                                                                                                                                                   --allow-unauthenticated
                                                                                                                                                                                                                                                                                 ```
                                                                                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                                 ### Step 5: Get Your URL
                                                                                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                                 ```bash

                                                                                                                                                                                                                                                                                 ```
                                                                                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                                 Your URL will be: `https://atlas-backend-xxxxx.a.run.app`

                                                                                                                                                                                                                                                                                                                                                                                  ## Post-Deployment Checklist
                                                                                                                                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                                                                                  After deploying to any platform:
                                                                                                                                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                                                                                  ### 1. Test API Endpoints
                                                                                                                                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                                                                                  ```bash
                                                                                                                                                                                                                                                                                                                                                                                  # Test health check
                                                                                                                                                                                                                                                                                                                                                                                  curl https://your-deployed-url/api/health

                                                                                                                                                                                                                                                                                                                                                                                  # Test chat endpoint
                                                                                                                                                                                                                                                                                                                                                                                  curl -X POST https://your-deployed-url/api/atlas/chat \
                                                                                                                                                                                                                                                                                                                                                                                    -H "Content-Type: application/json" \
                                                                                                                                                                                                                                                                                                                                                                                    -d '{
                                                                                                                                                                                                                                                                                                                                                                                      "message": "What do you do?",
                                                                                                                                                                                                                                                                                                                                                                                      "visitorId": "test_user",
                                                                                                                                                                                                                                                                                                                                                                                      "conversationHistory": []
                                                                                                                                                                                                                                                                                                                                                                                    }'

                                                                                                                                                                                                                                                                                                                                                                                  # Check response contains "response", "detectedIntent", etc.
                                                                                                                                                                                                                                                                                                                                                                                  ```
                                                                                                                                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                                                                                  ### 2. Set CORS Correctly
                                                                                                                                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                                                                                  Update `server.js` with your frontend domain:
                                                                                                                                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                                                                                  ```javascript
                                                                                                                                                                                                                                                                                                                                                                                  const cors = require('cors');

                                                                                                                                                                                                                                                                                                                                                                                  app.use(cors({
                                                                                                                                                                                                                                                                                                                                                                                    origin: ['https://yourdomain.com', 'http://localhost:3000'],
                                                                                                                                                                                                                                                                                                                                                                                    credentials: true
                                                                                                                                                                                                                                                                                                                                                                                  }));
                                                                                                                                                                                                                                                                                                                                                                                  ```
                                                                                                                                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                                                                                  ### 3. Update Frontend
                                                                                                                                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                                                                                  In your portfolio's JavaScript, update the API URL:
                                                                                                                                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                                                                                  ```javascript
                                                                                                                                                                                                                                                                                                                                                                                  const ATLAS_API_URL = 'https://your-deployed-backend-url';

                                                                                                                                                                                                                                                                                                                                                                                  // Use in fetch calls
                                                                                                                                                                                                                                                                                                                                                                                  const response = await fetch(`${ATLAS_API_URL}/api/atlas/chat`, {
                                                                                                                                                                                                                                                                                                                                                                                    method: 'POST',
                                                                                                                                                                                                                                                                                                                                                                                    headers: { 'Content-Type': 'application/json' },
                                                                                                                                                                                                                                                                                                                                                                                    body: JSON.stringify({
                                                                                                                                                                                                                                                                                                                                                                                      message: userMessage,
                                                                                                                                                                                                                                                                                                                                                                                      visitorId: getOrCreateVisitorId(),
                                                                                                                                                                                                                                                                                                                                                                                      conversationHistory: getCurrentConversationHistory()
                                                                                                                                                                                                                                                                                                                                                                                    })
                                                                                                                                                                                                                                                                                                                                                                                  });
                                                                                                                                                                                                                                                                                                                                                                                  ```
                                                                                                                                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                                                                                  ### 4. Set Up Supabase
                                                                                                                                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                                                                                  1. **Create Supabase Project**
                                                                                                                                                                                                                                                                                                                                                                                  2.    - Go to https://supabase.com
                                                                                                                                                                                                                                                                                                                                                                                        -    - Click "New Project"
                                                                                                                                                                                                                                                                                                                                                                                             -    - Copy Project URL and Anon Key
                                                                                                                                                                                                                                                                                                                                                                                              
                                                                                                                                                                                                                                                                                                                                                                                                  - 2. **Initialize Database**

                                                                                                                                                                                                                                                                                                                                                                                                                                                        ## Troubleshooting Deployment Issues
                                                                                                                                                                                                                                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                                                                                                                                                                                                                                        ### Issue: "Cannot find module 'express'"
                                                                                                                                                                                                                                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                                                                                                                                                                                                                                        **Solution**: Make sure `npm install` runs successfully during build
                                                                                                                                                                                                                                                                                                                                                                                                                                                        - Check `package.json` exists in correct directory
                                                                                                                                                                                                                                                                                                                                                                                                                                                        - - Check `.gitignore` doesn't exclude `package.json`
                                                                                                                                                                                                                                                                                                                                                                                                                                                          - - Manually run `npm install` to test locally
                                                                                                                                                                                                                                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - ### Issue: "PORT is not defined"
                                                                                                                                                                                                                                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - **Solution**: Express server should use environment PORT:
                                                                                                                                                                                                                                                                                                                                                                                                                                                            - ```javascript
                                                                                                                                                                                                                                                                                                                                                                                                                                                              const PORT = process.env.PORT || 3001;
                                                                                                                                                                                                                                                                                                                                                                                                                                                              app.listen(PORT, () => console.log(`Server running on port ${PORT}`));
                                                                                                                                                                                                                                                                                                                                                                                                                                                              ```
                                                                                                                                                                                                                                                                                                                                                                                                                                                              
                                                                                                                                                                                                                                                                                                                                                                                                                                                              ### Issue: "Cannot POST /api/atlas/chat"
                                                                                                                                                                                                                                                                                                                                                                                                                                                              
                                                                                                                                                                                                                                                                                                                                                                                                                                                              **Solution**: Router not defined. Check server.js has:
                                                                                                                                                                                                                                                                                                                                                                                                                                                              ```javascript
                                                                                                                                                                                                                                                                                                                                                                                                                                                              app.post('/api/atlas/chat', async (req, res) => { ... });
                                                                                                                                                                                                                                                                                                                                                                                                                                                              ```
                                                                                                                                                                                                                                                                                                                                                                                                                                                              
                                                                                                                                                                                                                                                                                                                                                                                                                                                              ### Issue: "ANTHROPIC_API_KEY is undefined"
                                                                                                                                                                                                                                                                                                                                                                                                                                                              
                                                                                                                                                                                                                                                                                                                                                                                                                                                              **Solution**: Environment variable not set
                                                                                                                                                                                                                                                                                                                                                                                                                                                              - Verify it's in platform's environment variables
                                                                                                                                                                                                                                                                                                                                                                                                                                                              - - Check exact name matches (case-sensitive)
                                                                                                                                                                                                                                                                                                                                                                                                                                                                - - Restart service after setting
                                                                                                                                                                                                                                                                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                                                                                                                                                                                                                  - ### Issue: "CORS error in browser"
                                                                                                                                                                                                                                                                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                                                                                                                                                                                                                  - **Solution**: CORS not configured for your domain
                                                                                                                                                                                                                                                                                                                                                                                                                                                                  - - Add your domain to `cors()` configuration in server.js
                                                                                                                                                                                                                                                                                                                                                                                                                                                                    - - Redeploy after changing
                                                                                                                                                                                                                                                                                                                                                                                                                                                                      - - Test with curl first (doesn't require CORS)
                                                                                                                                                                                                                                                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                                                                                                                                                                                                                                        - ### Issue: "502 Bad Gateway" or "Service Unavailable"
                                                                                                                                                                                                                                                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                                                                                                                                                                                                                                        - **Solution**: Server crashed or not responding
                                                                                                                                                                                                                                                                                                                                                                                                                                                                        - - Check platform logs for errors
                                                                                                                                                                                                                                                                                                                                                                                                                                                                          - - Check `npm start` command works locally
                                                                                                                                                                                                                                                                                                                                                                                                                                                                            - - Make sure server listens on correct PORT
                                                                                                                                                                                                                                                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                                                                                                                                                                                                                                              - ### Issue: "Timeout" errors
                                                                                                                                                                                                                                                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                                                                                                                                                                                                                                              - **Solution**: API call taking too long
                                                                                                                                                                                                                                                                                                                                                                                                                                                                              - - Check Anthropic API key is valid
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                - - Check network is working (test curl)
                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  - - Increase timeout on frontend if needed
